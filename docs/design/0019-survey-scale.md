# 0019: 数十〜百本規模の調査と試験要件

状態: Implemented
日付: 2026-10-12 JST
対象タスク: P20
関連: [調査の6段階](0017-research-flow-and-paper-cache.md)、[チュートリアル](0018-tutorial.md)、[Codexの調査](0012-codex-research-modes.md)

## 目的と範囲

ユーザー指示（2026-10-12）「調査プロンプトの修正によって数十〜百規模の論文を調査できるはず、それができているかテスト要件」。新規調査で論文を数十〜百本扱い、それを確かめる試験要件を決める。

## 変更

- 論文の深さを2段にする。1（抽象）で一次論文を広く30〜100本程度（古典、引用の多いもの、系統ごとの最初から最新まで、最近の転換点、強いベースライン）を理由つきで挙げ、そのうち10〜20本に印を付ける。2（具体）で印の論文を本文まで読み（要点・出典・和訳）、ほかは書誌と貢献をアブストラクトや一覧で確かめる。出力では挙げた論文をすべてPaperにし、年・会議の略称・DOI/arXiv ID/URL・一言概要・proposes/addressesで系統か課題に位置づける。同じ論文を2度入れない。要点は深く読んだ論文だけ。
- 変更案の操作の上限を300から2000に上げた（patch schema）。
- 実行の上限を新規調査45分・修正20分に延ばした。

## 試験要件（採点表）

`assessSurvey`（`packages/domain/src/survey-assessment.ts`）。構造の検査で、内容の正しさは保証しない。

| 要件 | 基準 |
| --- | --- |
| 論文の数 | 30本以上（目標は数十〜百本） |
| 深く読んだ論文 | 10本以上に、出典つき・貢献ありの要点 |
| 書誌 | すべての論文に年と、DOI・arXiv ID・URLのいずれか |
| 位置づけ | すべての論文が手法・課題・ナレッジ・チュートリアル・関係のどれかにつながる |
| 重複なし | DOI→arXiv ID→タイトルと年で同じ論文が無い |
| 時間の幅 | 論文の年の幅が8年以上（古典から最新まで） |
| 手法 | 6つ以上、系統3つ以上、すべての手法が系統に属する |
| 課題 | 4〜12、すべてに達成度の主張 |
| ナレッジ | 8分類のうち5つ以上（分野によって無い層があるため2026-10-12に6から変更） |
| チュートリアル | 0018の要件をすべて満たす |

実行結果は `npm run survey:assess -- .poc/runs/<run id>`（または patch.json）で採点し、満たさない要件があれば終了コード1を返す。新規調査（空の調査が基）の変更案が対象。単体試験は、小さいサンプルが規模の要件だけを落とすこと、規模を満たした調査が全要件を満たすこと、各要件が単独で落ちることを確かめる。

## 実測

実Codexでの結果は[状態・実測](../status.md)に記録する。要件を満たさなかった項目は、Promptの調整か要件の見直しの材料にする。
