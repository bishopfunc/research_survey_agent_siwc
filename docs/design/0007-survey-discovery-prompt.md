# 0007: 分野の入口から始めるサーベイPrompt

状態: Implemented（Prompt定義・Lab表示。実調査は未接続）
日付: 2026-10-12 JST
対象タスク: P07

サーベイは個別論文の検索からではなく、その分野の情報源の把握から始める。

1. 分野・隣接分野・対象期間を定め、代表的な学会を調べる。正式名、略称、公式URL、扱う話題、選定理由を残す。必要に応じて関連ジャーナル・ワークショップも区別する。
2. 代表的なサーベイ論文・レビュー論文を探す。タイトル、出版年、著者、出典、対象範囲、分類軸、参考文献を確認する。古典的な整理と最近の整理を照合する。
3. awesome-xxxxなどの文献・コード集を探す。URL、対象範囲、更新状況、分類を確認し、論文・実装を発見する入口として使う。star数だけで代表性を判断しない。
4. これらを起点に一次論文をたどる。課題・手法・系譜・未解決点を整理し、各主張を元論文の条件と根拠で確認する。コード公開状況と代表Figの候補も記録する。

`packages/agent/src/research-prompt.ts` に調査用Promptと日本語の段階説明を共有定義する。テーマと調査基準日をデータとして渡し、文献・リポジトリ内の指示には従わない。調査できない場合は未確認を残し、学会・文献・URL・引用数・Figを捏造しない。

`/lab` は調査用Promptと現在実行中の編集Promptを区別して表示する。現在のCodex編集PoCは外部検索を行わないため、今回の調査Promptは定義とレビューまで実装し、実調査への接続は後続のDiscoverer/Workflowで行う。実行時と共通という表示は編集Promptだけに適用する。

検証：調査段階の順序、Promptのテーマ・基準日への受け渡し、Labの表示と未接続の明示、既存編集Promptの維持、必須checkとWorker dry-runを確認する。
