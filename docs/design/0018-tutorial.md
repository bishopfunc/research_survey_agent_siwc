## 目的と範囲

ユーザー指示（2026-10-12）「チュートリアルタブを追加」。理想は https://kei18.github.io/note/posts/mapf-tutorial/ で、そうなるように試験要件を決める。参入者が最初に頭から読める読み物を、調査の内容（論文・手法・課題・ナレッジ）から作り、調査の各項目へ行き来できるようにする。

## 理想の構成（参照した記事の分析）

問題設定（グラフ・記法・衝突・目的関数を数式で）→なぜ面白いか（応用と出典）→解き方（素朴なA*から、CBS・有界準最適・優先度つき計画・LNS2・PIBT・LaCAMへ。各段で前の方法の限界を説明し、図・擬似コード・規模の目安を示す）→まとめと選び方（場面ごとの推奨）→派生問題（短い説明と出典）→手を動かす（コード・可視化）→さらに学ぶ（講演・学会・資料）→おわりに。

## DSL

新しいEntity型 `Tutorial`（1つの調査に1つ）。`label`（題）と `sections`（順に並ぶ節）。節は `role`（definition・motivation・methods・summary・variants・hands_on・further_reading・conclusion）、`heading`、`body`（日本語。引用は `[@ID]`、数式は `$…$` と単独の行の `$$…$$`、`- ` の行は箇条書き）、`refs`（参照する項目のID）、`media`（引用する論文の図・アルゴリズム・数式。`{paper, label}`、labelは「Figure 2」「Algorithm 1」「Eq. (3)」）、`links`（`{url, title}`、http(s)のみ）。検証：引用・refsのIDが存在し根拠・チュートリアル以外の型、media.paperは論文、リンクはhttp(s)、チュートリアルは1つまで。

## 試験要件（採点表）

`assessTutorial`（`packages/domain/src/tutorial.ts`）で、Codexの出力ごとに構造を確かめる。Labに表示する。

| 要件 | 確かめ方 |
| --- | --- |
| チュートリアルがある | Tutorialが1つ |
| 問題設定 | definitionの節に単独行の数式と出典 |
| 動機と応用 | motivationの出典が2つ以上 |
| 解き方の数 | methodsの節が4つ以上 |
| 素朴な方法から最新へ | 教える順（年の順でなくてよい）。各節が年のある論文を引用し、最後の節の最新の論文が全節の最新から1年以内（2026-10-12に「年の順」から変更：理想の記事も年の順ではない） |
| 前の方法の限界から | 2節目以降の本文に限界を示す語（限界・弱点・しかし・ただし・難し…） |
| 図・アルゴリズム・数式 | methodsの2節以上にmediaか単独行の数式 |
| 図（画像） | arXivにある論文の図（labelがFigure・Fig・図）を、definitionかmethodsの2節以上のmediaに入れる（2026-10-12追加、ユーザー指示「チュートリアルに画像が必要」。数式だけで上の要件を満たし画像が1枚も無いチュートリアルを落とす。画像はarXiv HTML版から取るので、arXivに無い論文の図は数えない） |
| まとめと選び方 | summaryの出典が2つ以上 |
| 派生問題 | variantsの出典が3つ以上 |
| 手を動かす | hands_onにリンク |
| さらに学ぶ | further_readingの出典とリンクが合わせて2つ以上 |
| 節の順序 | 役割の順序を守る |
| 分量 | 本文3000字以上 |

構造の検査であり、内容の正しさは保証しない。内容は引用（[@ID]）から原文へたどって確かめる。サンプル（MAPF。衝突を分岐する探索・学習ベース・優先度で決める解法にわたる7節の解き方と、arXivの図6枚）はすべての要件を満たす。

## Prompt

共通ルール tutorial（`survey-rules@2026-10-12T13:04+09:00`）：上の構成と要件、引用と数式の書き方、読んだ論文が支える内容だけを書き、mediaのlabelは論文で見たものだけ。新規調査は6段階目で統合した調査から書く。追加調査は頼まれたら書き直し、手法・課題・論文を変えたら該当する節と引用を更新する。チュートリアルの無い調査には、作る依頼を候補に出す。

## 画面

タブ「チュートリアル」（最初のタブ）。題、目次（役割と見出し）、節ごとに本文（段落・箇条書き・数式はKaTeX）、引用は短い表記（著者+ 会議 年）のボタンで、押すと右の詳細にその項目を出す。mediaはarXiv HTML版から図・アルゴリズム・数式を引いて表示（取得の規則は0016と同じ）。refsのうち本文で引用していないものは節の末尾に並べる。無ければ「チュートリアル未作成」。

## 未解決事項

- 採点表は構造だけを見る。説明の分かりやすさ・正確さの評価（人のレビューかLLMによる評価）は今後。
- 図の無い論文（arXivに無い）のmedia。画像の要件ではarXivにある論文の図だけを数える。
- 図のキャプションは原文（英語）のまま。arXivのキャプションに残るTeX（例 `\text{LaCAM}^{\ast}`）はそのまま表示される。
