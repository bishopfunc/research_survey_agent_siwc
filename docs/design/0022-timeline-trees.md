# 0022: 手法ツリーと課題ツリー（年×系統）

状態: Implemented（ローカルPoC）
日付: 2026-10-12 JST
対象タスク: P23
関連: [手法の系譜](0003-method-evolution.md)、[専門家水準へのキャッチアップ調査](0014-expert-catch-up-survey.md)

## 目的と範囲

ユーザー指示（2026-10-12）：

- 系統ツリーを「手法ツリー」に改める。年を左から右へ、行ごとに手法の系統。複数の系統に属する手法は曲がった矢印で示す。
- 課題ツリーも手法ツリーと同じUIにする。詳細欄には置かない。
- 代表論文は論文タブに移し、「すべて」と「代表論文」を分ける。

DSLとJSONは変えない。既存のMethod・Issue・Paper・Conceptと関係から投影する。

## 表示

手法タブと課題タブの中央に、同じ形のツリーを出す。

- 列は出版年の昇順。年の未取得は最後の列「未取得」にまとめる。列の幅は一定で、時間差の縮尺ではない。
- 行は系統。同じ行・同じ列に複数あれば、その行の中で縦に積む（行の中の段）。派生の連鎖はできるだけ同じ段に置く。
- 矢印は基→派生。同じ行・同じ段で右へ進む矢印は直線、それ以外（行をまたぐ、段が違う、年が逆か同じ）は曲線。
- 選んだ項目と、それにつながる矢印を強調する。項目を押すと詳細欄に出す。
- 広い場合はツリーの領域だけ横にスクロールし、行の見出しは左に固定する。

### 手法ツリー

- 行：系統（Method→Conceptのinstance_of）。系統の順は最も早い手法の年、系統の無い手法は最後の行「未分類」。
- 手法の年：代表論文（[0003](0003-method-evolution.md)と同じ。最も早い既知の出版年）。
- 矢印：extends・builds_on・specializes（実線）。
- 複数の系統に属する手法は、派生元のある系統の行（無ければ最初の系統の行）に1回だけ置き、ほかの系統の行から破線の曲線で結ぶ。起点はその行で手法より前の列にある最後の手法、無ければ行の見出し。その系統に派生元があれば派生の矢印で足りるので破線は引かない。
- 行の見出しを押すと系統の詳細を出す。派生関係の循環と、年の矛盾の警告は従来どおりツリーの上に出す。

### 課題ツリー

2026-10-12追記（ユーザー指示「手法ツリーのように行名が課題、1つ1つが論文」）：最初の版（行＝根の課題、項目＝課題）を次のように改めた。

- 行：課題。上位の課題の直後に下位の課題を並べ（深さ優先）、見出しは深さに応じて字下げし、点の色が課題の種類。論文が無い課題も行を残す。論文の無い課題が無ければ「未分類」の行は出ない。
- 項目：論文。年は論文の出版年。論文が取り組む課題（Paper.addresses と addresses関係。どちらも無ければ、提案する手法が取り組む課題）のうち、最も深い課題の行に置く。
- 上位の課題は下位の課題に含まれるので、論文が上位と下位の両方を挙げていても上位の行とは結ばない。関係の無い2つの課題に取り組む論文は、もう一方の行から破線の曲線で結ぶ（起点は手法ツリーと同じ規則）。
- 矢印：論文Pが提案する手法が、手法Mから派生（extends・builds_on・specializes）していれば、Mの代表論文→P。
- 項目の名前は提案する手法（無ければ論文の短い名前）、下に第一著者と会議・論文誌。
- 課題タブの切り替えは「ツリー」と「一覧」の1段だけ。種類の絞り込みは外し、種類は点の色と凡例で示す（ユーザー指示「2段階のタブ構造は気持ち悪い」）。何も選んでいないときの詳細欄は「未選択」。

### ツリーの分割（2026-10-12、ユーザー指示）

「課題タブは課題ツリー（課題どうしの親子）と論文ツリー（課題と論文の関係）、手法タブは手法ツリー（手法どうしの親子）と論文ツリー（手法と論文の関係）に分ける。1つの要素に複数を混ぜない。論文ツリーの項目はタイトル・年・会議名だけ」による。

- 課題タブ：課題ツリー・論文ツリー・一覧。課題ツリーは項目が課題だけ（行は根の課題ごとの系統、矢印はpart_of・specializesの上位→下位、課題の年はその課題か下位の課題に取り組む論文（直接、または取り組む手法の代表論文）の最も早い年）。論文ツリーは上の「課題ツリー」節の内容（行＝課題、項目＝論文）。
- 手法タブ：手法ツリー・論文ツリー。論文ツリーは行が手法（手法ツリーの順：系統ごと・年順、複数の系統に属する手法は最初の系統の位置に1回）、項目は論文。論文は提案した手法の行に置き、2つ以上の手法を提案した論文はほかの行から破線の曲線で結ぶ。手法を提案していない論文（定義・ベンチマークの論文、RHCRなど）は未分類の行。
- 論文の項目は課題・手法の論文ツリーで共通（`paperCard`）：題（2行まで）と「年 · 会議名」。手法名や著者は出さない。
- 課題と手法のつながり（addresses・introduces_issue）はツリーに描かず、詳細欄とつながり図で見る。
- 同じ年に始まる系統の順は、ラベルの `localeCompare` ではなくIDで決める（ブラウザとNodeで並びが変わったため）。
- 論文タブのカードの図は右端に置く（ユーザー指示）。

### 課題ツリーと手法ツリーに年は無い（2026-10-12、ユーザー指示）

課題ツリーと手法ツリーは年の列を持たず、左から右を親子の世代にする（親を持たない項目が0、それ以外は最も深い親の世代に1を足す。循環しても停止する。`generations`）。列の見出しは出さない。論文ツリーは年のまま。課題ツリーの行の並び（根の課題の順）は、取り組む論文の最も早い年で決める。

### 課題ツリーを手法ツリーと同じ形に（2026-10-12、ユーザー指示）

「課題を分けるのはやめる。単純に手法のように親子で。課題ツリーも手法ツリーのように一番左が親の課題」による。

- 課題ツリーは、左端の列（行の見出し）が根の課題（上位の課題を持たない課題）、その行の項目が下位の課題。根の課題の子が一番左の列で、孫が次の列（世代）。矢印は下位の課題どうしの上位→下位（根からの矢印は見出しに含まれるので描かない）。2つの根の下にある課題は最初の根の行に置き、もう一方の行から破線の曲線で結ぶ。
- 課題の種類（本質的課題・部分課題・手法依存）で画面を分けない：ツリーの点の色と凡例、一覧のカードと詳細の種類のチップを外した。DSLの `Issue.kind` は必須のまま残す（保存形式は変えない）。

### 課題と手法の英語表現（2026-10-12、ユーザー指示）

「課題と手法の下に英文の専門用語、論文で使われるような表現を書く」による。`Method.english_terms`（任意、最大5、重複なし。`Issue.english_terms` と同じ形）を追加した（[ADR 0010](../adr/0010-reuse-types-for-expert-survey.md)の「追加は任意項目だけ」に従う）。課題ツリー・手法ツリーの項目は、名前の下に最初の英語表現を出す。詳細欄には英語表現をすべて出す。Promptの手法の規則に英語表現を加え、サンプルの手法10個に入れた。

### 論文ツリーの項目に一文を足す（2026-10-12、ユーザー指示）

「課題論文ツリーに主張、手法論文ツリーにどんなもの？を描いてほしい」による。前の指示（題・年・会議名のみ）に、ツリーごとに一文を足す。

- 課題の論文ツリー：論文の主張（Paper.claims と supports関係のClaim）のうち、その論文が置かれた行の課題について（about）のものを優先し、無ければ最初の主張。主張が無い論文は足さない。
- 手法の論文ツリー：一言概要（one_line_summary、詳細欄の「どんなもの？」）。
- 論文の項目は大きくする（幅220・高さ128、題2行・年と会議・一文3行まで）。課題・手法ツリーの項目は従来の大きさ。

### タブの下の切り替え

ユーザー指示（2026-10-12）：上のタブ（チュートリアル・課題・手法・論文・ナレッジ）に件数を出さない。タブの下の切り替えは1段だけにし、課題（ツリー・一覧）・論文（すべて・代表論文）・ナレッジ（分類）で同じ部品（`SubTabs`、下線のタブ）を使う。手法タブは切り替えなし。

### 論文タブ

- 「すべて」と「代表論文」を切り替える。代表論文は手法の代表論文だけを、同じカードで出版年順に出す。カードに代表する手法の名前を出す。
- 手法タブの「代表論文」の切り替えは削除する。

## 契約

レイアウトは `packages/domain/src/timeline.ts` の純粋関数で計算し、画面は位置を描くだけにする。

- 入力：項目（id・年・属する行のキー、先頭が置く行）、行のキーの順、基→派生の関係。
- 出力：年の列、行（キーと段数）、項目の位置（列・行・段）、矢印（基・派生・種類・曲線か）。
- 手法は `buildMethodTree`（evolution.ts）、課題は `buildIssueTree`（issue-tree.ts）が入力を作る。循環があっても停止し、項目を落とさない。課題ツリーは項目の無い行も残す（`layoutTimeline` の allRows）。

旧来の年のレーン（`EvolutionNode.lane`・`laneCount`）は使わなくなったので削除する。

## 検証

- 年の列と未取得の列、同じ列の段、派生の連鎖が同じ段、直線と曲線、行をまたぐ派生、複数の系統の破線と起点、派生元がある系統では破線を引かない、未分類の行が最後。
- 課題の年が下位を含むこと、複数の上位、循環でも停止すること。
- 画面：サンプルで手法ツリー・課題ツリー・論文タブの切り替えをヘッドレスChromeで確認する。モバイル幅で横スクロールが領域内に収まること。
