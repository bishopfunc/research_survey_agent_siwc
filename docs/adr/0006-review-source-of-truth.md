# ADR 0006: レビューLabは実行時の定義を参照する

状態: Accepted
日付: 2026-10-12 JST
関連: [Lab設計](../design/0004-review-lab.md)

## 背景

UI、Agent Prompt、DSLをコアロジックとしてレビューする。説明だけを別管理すると、実装とレビュー資料がずれる。

## 判断

Promptを共有モジュールへ移し、Codex起動とLabが同じ指示文・実行条件を参照する。DSL表は実際のschemaから生成し、検証例は実際のvalidatorに通す。UIプレビューは製品コンポーネントを隔離モードで描画する。

## 影響

レビュー画面を更新するための定義の複製を減らせる。日本語の解説と図は実装変更時に照合する。レビューの確認済みは本人のメモであり、Agentやテストが代わりに承認したことを意味しない。
