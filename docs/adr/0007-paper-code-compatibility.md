# ADR 0007: コード公開情報を任意のPaperメタデータにする

状態: Accepted
日付: 2026-10-12 JST
関連: [コード公開状況](../design/0005-paper-code.md)

Paperに公開状況・公開URL・確認日を任意フィールドとして追加する。既存0.1.0のsnapshotはそのまま受け入れ、欠落は未確認と表示する。過去Commitへの補完や書き換えは行わない。

公開状況を必須化して保存データを移行する案は、既存の不変履歴を変えるため採用しない。未確認と「確認したが見つからず」を区別し、コードが見つからないことを非公開の証明にしない。更新は新Commitとして残す。
